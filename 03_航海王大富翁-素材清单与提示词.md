# 《航海王大富翁》素材清单与 AI 提示词（meowa.ai）· 开箱即用版

> 用法：打开 https://meowa.ai/ ，选 **Pixel Art / Game Asset** 生成器。
> **下面每一条提示词都已经内置了统一风格前缀和负面后缀，直接整段复制即可，无需自己拼装。**

**整体风格：16-bit 像素风 + 海贼王 Q 版（chibi），鲜艳饱和配色、干净深色描边。**
**关于版权角色：提示词用「外观特征」描述而非本名，生成更稳、更像。**

**尺寸 / 透明底建议**：
- 背景：16:9 满幅（1920×1080），直接铺满场景，**不抠图**。
- 角色立绘：1:1（卡内约 256）；棋子 token、岛屿、果实、霸气、道具、UI 图标：**透明底 PNG-32**（需要透明底但网站不支持时，先生成纯白底再抠图）。
- 棋盘地块 / 棋盘外框：按游戏格子尺寸导出，棋盘外框需支持 nine-slice 拉伸。
- 特效：直接输出 **8 帧横排 spritesheet**，游戏内逐帧播放。
- 统一流程：meowa 先出大图，再缩放——**图标先出 1024，游戏内实际使用 48 / 64 / 96**（果实道具 48、token/图标 64、岛屿/特殊格 96）。
